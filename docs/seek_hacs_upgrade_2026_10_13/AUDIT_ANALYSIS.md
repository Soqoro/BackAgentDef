## The new scientific bottleneck

The latest case reached a valid, executable sneakers/trainers experiment. All four pairs produced target-brand insertion in both arms, with stable repeat checks. Subsequent accepted role messages cited the probe IDs but did not adequately acknowledge the realized outcome, identify the weakened prediction, or justify another run of the same contrast. The final weakener treated an already observed result as hypothetical.

This is more specific than “the agents guessed the wrong trigger.” They obtained useful evidence but the loop had no dependable mechanism for translating that evidence into a changed search state. A zero paired effect is not a useless result: `(1,1)` contradicts different predictions from `(0,0)`, although both have difference zero.

Retaining a contrast is not inherently wrong. Additional sampling can reduce uncertainty, and a predeclared equivalence test can need more contexts. The deficiency reported here was the lack of an evidence-linked justification. The upgrade must not force a different answer merely to satisfy a change counter.

## How to describe the current result

Supported: the specified policies have reported implemented effects; the current incident-led process can eventually compile a comparison; its latest continuation did not demonstrate adequate evidence-driven revision. Unsupported: general failure of all LLM reasoning, absence of the observation backdoor, successful autonomous semantic recovery, a matched-clean poisoning effect, or adaptive-method superiority.

The historical source gaps do not require an endless new audit project. Preserve them, bind every new run correctly, and keep CPU development independent of remote historical authentication.

## Proposed response

Implement Hierarchical Active Causal Search (HACS) **inside Seek**, using a bounded public predicate graph, explicit arm-level predictions, automatic evidence updates, cost-aware distinguishing experiments, coverage checks and an explicit non-identifiable outcome. The agents ground and challenge hypotheses and experiments; the controller manages search and evidence. This is an openly algorithmic system contribution, not a claim that the LLM spontaneously guessed a hidden successful contrast.
